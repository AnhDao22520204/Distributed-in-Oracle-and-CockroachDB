# Requirement 1 – CockroachDB

Files:

- `create_tables.sql`: e-commerce database and tables.
- `insert_data.sql`: synthetic test dataset.
- `partition_tables.sql`: logical three-range partitioning example.

The generated dataset targets:

- 100 stores
- 10,000 users
- 10,000 products
- 10,000 inventory rows
- 1,000,000 invoices
- 3,000,000 invoice details
- 10,000 reviews
- 1,000,000 payments
